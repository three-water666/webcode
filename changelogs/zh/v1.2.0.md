# v1.2.0 (2026-09-07)

## 功能

- 新增 `webcodeGateway.idleTimeoutMinutes` 设置，支持 5 至 240 分钟的空闲超时，
  默认仍为 30 分钟；只有通过认证的网关活动才会重置空闲计时器。 (#77)

## 改进

- 加固网关连接：使用短时有效、一次性连接码替代 URL 中的 API 令牌，仅允许 WebCode 浏览器插件
  兑换连接码，并在网关停止或重启时撤销会话，同时保持多个浏览器连接并发可用。
  新增浏览器消息校验，并要求审批操作由可信的用户输入触发。 (#77)
- 为浏览器工作面板中的工具活动提供更多空间，默认折叠下一轮 follow-up 区域并保留草稿和排队消息。
  保持确认、移除按钮可见，新增居中空状态，并让紧凑入口的宽度随工具和投递状态变化平滑过渡。

## 修复

- 稳定隔离浏览器的桥接升级：固定插件身份、校验暂存更新，并协调多个 VS Code 窗口的安装与启动。
  新增重启提示和旧版桥接恢复指引，改进浏览器进程识别，并将开发、测试桥接安装与正式安装隔离。 (#77)

## 工程

- 更新发版技能，根据最终改动及其兼容性影响选择主版本、次版本或补丁版本，
  并在准备发版文件前说明判断依据；用户明确指定的版本优先。
