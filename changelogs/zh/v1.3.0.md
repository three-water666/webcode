# v1.3.0 (2026-11-14)

## 功能

- 新增按站点配置的自动发送延迟，通过 `webcodeGateway.aiSites[].autoSendDelaySeconds`
  设置 0 至 300 秒等待时间；DeepSeek 默认 10 秒，其他站点默认不额外等待。
  工具结果回填后的自动发送及后续重试均遵守延迟；工作面板显示工具进度、发送倒计时和最终状态，
  编辑聊天输入框即可取消待发送消息。已确认的补充消息成功写入输入框后立即出队，
  避免取消自动发送并手动发送后再次重复追加。 (#82, closes #80)
