# v1.3.0 (2026-11-14)

## Features

- Added per-site auto-send delays through `webcodeGateway.aiSites[].autoSendDelaySeconds`,
  configurable from 0 to 300 seconds, with a 10-second default for DeepSeek and no additional
  wait for other sites. Automatic sends and retries after tool-result delivery respect the
  delay. The work panel shows tool progress, send countdowns, and final outcomes; editing
  the chat input cancels a pending send. Confirmed follow-ups leave the queue once written
  into the input, preventing duplicate additions after cancelling auto-send and sending
  manually. (#82, closes #80)

## Documentation

- Documented the risks of rate limits, account restrictions, and bans from web automation,
  along with how webcode works, web AI context and generation limits, the lack of context
  compaction, and its suitability for shorter tasks.
- Added a recorded DeepSeek pelican demo, the generated SVG, and a gateway startup
  screenshot to the bilingual READMEs, along with the list of built-in AI platforms.

## Engineering

- Rendered SVG images as links in the generated Marketplace README so VSIX packaging
  succeeds without unsupported SVG image embeds.
