# v1.2.0 (2026-09-07)

## Features

- Added the `webcodeGateway.idleTimeoutMinutes` setting, configurable from 5 to 240 minutes
  with a 30-minute default. Only authenticated gateway activity resets the idle timer. (#77)

## Improvements

- Hardened gateway connections with short-lived, single-use launch codes in place of API
  tokens in URLs, restricted code redemption to the WebCode browser extension, and revoked
  sessions when the gateway stops or restarts while preserving concurrent browser connections.
  Added browser message validation and required trusted user input for approval actions. (#77)
- Gave tool activity more space in the browser work panel and collapsed next-turn follow-ups
  by default while preserving drafts and queued messages. Kept confirmation and removal
  controls visible, added a centered empty state, and smoothed compact launcher width changes
  as tool and delivery states update.

## Fixes

- Stabilized isolated browser bridge upgrades with a fixed extension identity, validated
  staged updates, and coordination across VS Code windows. Added restart prompts and
  recovery guidance for outdated bridges, improved browser process detection, and isolated
  development and test bridge installations from production installations. (#77)

## Engineering

- Updated the release skill to choose major, minor, or patch versions from the final changes
  and their compatibility impact, and explain the choice before preparing release files.
  Explicitly requested versions take precedence.
